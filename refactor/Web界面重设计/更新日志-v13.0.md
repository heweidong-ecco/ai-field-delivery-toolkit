## 1. 本轮变更

### 核心：现代设计系统（`web/style.css` 完整重写，779 行，5 节）

1. **设计令牌（CSS 自定义属性）**：品牌蓝 `--primary:#2563eb`；中性灰阶（`--text/--text-2/--text-muted`）；语义色齐全（ok/warn/danger/info 各带 `-soft/-border/-ink` 变体）；统一圆角/阴影/间距尺度/字体栈（中文友好系统栈）。
2. **布局重构（`web/index.html`）**：固定顶栏（品牌 + 服务状态 `#health-status`）+ 左侧深色侧边栏（11 个 `.nav-item`，emoji 图标 + 文字，`data-tab` 与 section id 一一对应）+ 主内容区。响应式：≤900px 侧边栏变 off-canvas 抽屉（汉堡 + 遮罩，内联脚本仅负责开合，不触碰 app.js）。
3. **统一组件库**：面板/卡片（圆角 + 细阴影）、现代表格（表头底色/行 hover/圆角溢出）、按钮（primary/ghost/danger）、胶囊徽章（ok/del/warn/critical/info）、alert 四态、统计卡、渐变柱状图、可折叠文章排版、作战台统计卡、统一 focus ring。
4. **兼容性**：app.js 生成 HTML 用到的全部 class 均已样式化（`badge/panel/card/ghost/primary/kv/hint/alert/grid/stack/metric-cards/chart/article/warroom-*/hidden/health` 等）；`.badge.warn`/`.alert.warn` 别名兜底。

### 关键保障：零破坏

- `web/app.js` **零改动**（`node --check` 通过）。
- 交叉核对：app.js 引用的 92 个静态 ID 全部存在于 HTML 且无重复；76 个表单 `name` 属性 **0 丢失、0 新增**；nav 的 11 个 `data-tab` 与 11 个 section id 一一对应。
- 服务验证：`/` 返回新 HTML，`/style.css`（text/css）与 `/app.js` 正常服务。
