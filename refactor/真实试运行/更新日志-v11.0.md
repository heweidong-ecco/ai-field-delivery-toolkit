## 1. 本轮变更

### A. 固定真实数据集（提交仓库，不依赖 tmp/）

1. **`examples/data/manufacturing_sensors.csv`**（42 行）：制造业传感器真实列结构（`sensor_id / device_name / metric / reading / unit / ts / status`），设备覆盖注塑机 / CNC 加工中心 / 冲压机 / 空压机 / 装配线，指标含温度 / 压力 / 振动 / 转速 / 电流，带时间戳与状态（正常/预警/报警）。从历史产物 `tmp/web/dataprep/<run_id>/upload/sensor*.csv` 提炼列结构后人工造得更完整真实，**非教学场景**。
2. **`examples/data/retail_inventory.csv`**（32 行）：零售库存真实列结构（`sku / name / category / stock_qty / cost_price / supplier / last_updated`），32 个 SKU 覆盖滤清器 / 制动 / 点火 / 传动 / 养护 / 底盘 / 轮胎等汽配品类。

### B. 端到端试运行脚本 `examples/pilot_example.py`

同一客户「某汽车零部件制造厂」跑**完整项目端到端**，全部走真实 API（FastAPI TestClient，与前端契约一致）：

1. **需求诊断**：`POST /diagnosis/start` → `/diagnosis/review`（人工用 Generator 分数）→ `/diagnosis/finalize`（confirmed=true）→ 自动生成交付物（HTML/PDF）+ 注册诊断方案资产 + 挂项目档案。
2. **数据作战流**：`POST /dataprep/create`（制造业传感器 CSV，project_id=该项目）→ 顺序推进 `annotate → eval_set → knowledge_base`（知识库步骤自动索引 ChromaDB）→ `POST /dataprep/{id}/deposit` 沉淀 4 类资产（评测集 / 知识库分块 / 清洗规则 / 质量报告）。
3. **原型 + RAG**：`POST /prototype/run`（knowledge_qa 模板，带 `kb_run_id` = 数据作战流 run_id，传 `project_id` 验证数据门禁放行，RAG 回答带引用）。
4. **字段映射**：`POST /mapping/create` → `/mapping/{id}/samples`（导入真实样例 CSV）→ `/mapping/{id}/validate`（实跑校验）→ `/mapping/{id}/export`（导出适配器 + 注册 mapping_config 资产）。
5. **部署配置**：`POST /deploy/run`（docker-compose，生成 Dockerfile/compose + degradation.yaml）。
6. **项目作战台**：`GET /projects/{pid}/warroom` 确认全分区聚合（诊断/数据/映射/交付物/资产/RAG/工作流进度）。
7. **交付物包**：诊断交付物 + `POST /cases/create-doc-package`（confirmed=true，门禁放行）→ 聚合到 `tmp/web/pilot/<客户>/`（客户项目总览.md + 诊断交付物.html 副本 + 项目文档包.html 副本 + warroom.json 快照 + 免责声明）。

**LLM 策略（诚实标注）**：
- 默认真调 DeepSeek（仓库 `.env` 有 key）：诊断 4 次 + 映射校验 6 次 + 原型 1 次 + 文档包 1 次 ≈ 12 次 LLM 调用。
- `--stub` 全部打桩（确定性 JSON / 固定文本 / 固定哈希嵌入），可复现、CI 用、秒级完成。
- 输出报告 `llm_mode` 字段诚实标注 `real` / `stub`。

**幂等**：每次运行新建 run_id，不覆盖旧产物；客户项目按客户名复用（`_ensure_project` 既有语义），warroom 聚合诚实含该客户全部历史产物。

### C. 客户交付物包（可发客户）

```bash

# 打桩模式（可复现、CI 用、秒级）
python examples/pilot_example.py --stub --max-rows 8
# → 客户交付物包默认在 tmp/web/pilot/某汽车零部件制造厂/

# 真调 DeepSeek（仓库 .env 有 key，约 2-4 分钟，≈12 次 LLM 调用）
python examples/pilot_example.py --pilot-dir /tmp/pilot_real
# → 输出 llm_mode=real，报告各产物 URL / 分区计数 / 门禁状态

# 回归
```
