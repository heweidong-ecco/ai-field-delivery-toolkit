```markdown
# 组织手册更新记录

## 更新 1：数据准备器
- PDF 解析需区分文字版和扫描版，扫描版需 OCR 或明确提示
- 去重策略应使用相似度阈值而非完全一致

- 部署前必须执行环境变量检查脚本
- Docker 部署时需确保宿主机端口不冲突

## 更新 3：原型组装器
- 流式输出必须有自动重连机制
- 重连使用指数退避，最大间隔不超过 30 秒
```

## 五、数据飞轮闭环

### 5.1 反馈回流

```bash
# 收集用户点踩反馈
python -c "
from data_flywheel.pipeline import DataFlywheelPipeline
flywheel = DataFlywheelPipeline(storage_path='pilot/annotation_pool.json')
flywheel.record_feedback(
    request_id='pilot-req-001',
    user_input='如何部署工具包？',
    model_output='使用Docker部署。',
    feedback_type='dislike',
    note='回答太简短，缺少具体步骤',
)
flywheel.feedback_collector.save('pilot/annotation_pool.json')
print('反馈已记录')
"
```

### 5.2 评测集更新

```bash
# 从标注池更新评测集（假设已有 eval_set.json）
python -c "
from data_flywheel.pipeline import DataFlywheelPipeline
flywheel = DataFlywheelPipeline(storage_path='pilot/annotation_pool.json')
result = flywheel.update_eval_set(
    eval_set_path='pilot/data_prep_output/eval_set.json',
    num_samples=10,
    output_path='pilot/eval_set_updated.json',
)
print(f'评测集更新完成，新增 {result[\"added_count\"]} 条')
"
```

### 5.3 覆盖率报告

```bash
# 生成评测集覆盖率报告（基于 metadata 或内容长度）
python -c "
import json
with open('pilot/eval_set_updated.json', 'r', encoding='utf-8') as f:
    eval_set = json.load(f)
total = len(eval_set)
short = sum(1 for item in eval_set if len(item['instruction']) < 100)
medium = sum(1 for item in eval_set if 100 <= len(item['instruction']) < 500)
long = sum(1 for item in eval_set if len(item['instruction']) >= 500)
print(f'评测集总数: {total}')
print(f'短文本: {short} ({short/total:.0%})')
print(f'中文本: {medium} ({medium/total:.0%})')
print(f'长文本: {long} ({long/total:.0%})')
"
```
