# 中间产物清理报告

经过全面检查，识别出以下**需要删除或清理**的内容。分为「必须删除的临时文件」「需要修改的残留代码」「可选的清理项」三类。

## 一、必须删除的临时文件（运行时生成，不应提交）

这些文件是运行测试和示例时自动产生的，应由 `.gitignore` 管理，但如果已经生成在本地仓库中，需要手动清理。

| 文件/目录                      | 产生原因           | 处理方式               |
| ------------------------------ | ------------------ | ---------------------- |
| `__pycache__/`（所有子目录下） | Python 自动缓存    | 删除全部               |
| `.pytest_cache/`               | pytest 运行缓存    | 删除                   |
| `logs/*.log`                   | 日志系统输出       | 删除全部日志文件       |
| `annotation_pool.json`         | 数据飞轮示例运行   | 删除                   |
| `eval_set.json`                | 数据飞轮示例运行   | 删除                   |
| `eval_set_updated.json`        | 数据飞轮示例运行   | 删除                   |
| `dashboard.json`               | 监控示例运行       | 删除                   |
| `crop_plan.json`               | 裁剪引擎示例运行   | 删除                   |
| `diagnosis_report.json`        | 诊断器示例运行     | 删除                   |
| `project_assets.json`          | 资产导出示例运行   | 删除                   |
| `cleaned_data.json`            | 数据准备器示例运行 | 删除                   |
| `quality_report.json`          | 数据准备器示例运行 | 删除                   |
| `cleaning_stats.json`          | 数据准备器示例运行 | 删除                   |
| `.release_prev_version`        | 发布脚本记录       | 删除（或保留用于回滚） |

**清理命令**：


# 删除 Python 缓存
find . -type d -name "__pycache__" -exec rm -rf {} + 2>/dev/null
find . -type f -name "*.pyc" -delete 2>/dev/null

# 删除测试/运行临时产物
rm -rf .pytest_cache
rm -rf logs
mkdir -p logs && touch logs/.gitkeep   # 如需保留空日志目录

# 删除示例运行产生的临时 JSON 文件
rm -f annotation_pool.json eval_set.json eval_set_updated.json dashboard.json \
      crop_plan.json diagnosis_report.json project_assets.json \
      cleaned_data.json quality_report.json cleaning_stats.json

# 删除发布脚本的本地版本记录
rm -f .release_prev_version

# 删除虚拟环境（如果有）
rm -rf venv .venv
