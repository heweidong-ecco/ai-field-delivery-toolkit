

以下为工具包 MVP 的功能边界。

| 模块             | MVP 包含                                                                                                                           | MVP 不包含                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **统一底座**     | 配置中心、安全基座（PII+注入+审核）、日志、版本、降级                                                                              | 完整插件热加载系统                             |
| **数据准备器**   | 数据接入（CSV/JSON/PDF/DB）、质量评估、一键清洗、评测集构建                                                                        | 完整标注工作台、知识库自动构建                 |
| **原型组装器**   | 3 个场景模板（知识问答/信息抽取/多步推理）、Agent Harness 基础、ReAct + Plan-and-Execute、短期记忆、工具调用、结构化输出、流式输出 | 完整 Multi-Agent、语义记忆、技能记忆、自动评估 |
| **五步裁剪引擎** | 7 类约束输入、五步按序执行、裁剪方案输出、方案版本                                                                                 | 自动决策建议、多方案对比                       |
| **部署加固器**   | 一键 Docker 化、Compose 部署、降级预案、回滚 ≤5 分钟                                                                               | K8s、金丝雀发布、多租户配置界面                |
| **需求诊断器**   | AI 适用性检查清单、访谈模板、验收人识别、报告模板                                                                                  | AI 自动诊断                                    |
| **监控开箱器**   | 基础看板（成功率/延迟/token）、3 类告警                                                                                            | 全链路追踪、成本报表                           |
| **数据飞轮器**   | 点踩回流标注池、手动评测集更新、项目结束资产清单                                                                                   | 自动评测集更新、自动优化                       |


### 统一底座

| 功能     | MVP 包含                                      | 说明                                         |
| -------- | --------------------------------------------- | -------------------------------------------- |
| 配置中心 | ✅ 统一配置入口，支持环境变量和 YAML，模块注册 | 所有模块通过 `core.config.settings` 读取配置 |
| 安全基座 | ✅ PII 脱敏、提示词注入拦截、输出审核（骨架）  | 默认开启，不可关闭                           |
| 日志系统 | ✅ 统一结构化日志，控制台 + 文件，按天滚动     | 基于 loguru，所有模块共用                    |
| 版本管理 | ✅ 代码、提示词、模板三版本记录和查询          | 内存记录，不持久化                           |
| 降级管理 | ✅ 模型调用 → 缓存 → 规则 → 人工 三级降级      | 统一入口，所有 AI 调用必须经过               |

### 数据准备器

| 功能       | MVP 包含                                   | 说明            |
| ---------- | ------------------------------------------ | --------------- |
| 数据接入   | ✅ CSV、JSON、PDF、数据库连接               | 4 种接入方式    |
| 质量评估   | ✅ 格式完整率、重复率、PII 检测、覆盖性报告 | 输出质量报告    |
| 一键清洗   | ✅ 去重、格式归一、异常过滤、脱敏           | 清洗正确率 ≥95% |
| 评测集构建 | ✅ 分层抽样、难度分布、核心场景覆盖         | 覆盖率 ≥80%     |
| 数据版本   | ✅ 清洗规则版本、数据版本记录               | 可追溯          |

### 原型组装器

| 组件          | MVP 包含                                           | 说明                   |
| ------------- | -------------------------------------------------- | ---------------------- |
| Agent Harness | ✅ 生命周期管理、状态保存恢复、资源配额             | 基础版                 |
| Agent Loop    | ✅ ReAct、Plan-and-Execute 两种循环                 | 可中断、可恢复         |
| 记忆系统      | ✅ 短期记忆（会话上下文）、长期记忆（基础用户事实） | 不做语义记忆、技能记忆 |
| 工具调用      | ✅ 工具注册、权限校验、调用审计、超时处理           | 基础版                 |
| 上下文工程    | ✅ token 预算强制、上下文压缩、多租户隔离（占位）   | 预算强制执行           |
| 结构化输出    | ✅ Schema 验证、重试 3 次、降级默认输出             | 可靠输出               |
| 流式输出      | ✅ SSE、断线重连、背压                              | 稳定可恢复             |
| 场景模板      | ✅ 知识问答 Agent、信息抽取 Agent、多步推理 Agent   | 3 个模板               |

### 五步裁剪引擎

| 功能     | MVP 包含                                             | 说明                 |
| -------- | ---------------------------------------------------- | -------------------- |
| 约束输入 | ✅ 预算、硬件、环境、数据规模、用户量、合规、时间窗口 | 7 类约束             |
| 五步执行 | ✅ 质疑 → 删除 → 简化 → 加速 → 自动化                 | 按序执行，记录每一步 |
| 方案输出 | ✅ 模块启用/简化/删除清单、部署配置建议               | 生成 JSON 方案       |
| 方案版本 | ✅ 按客户独立存储                                     | 可追溯               |

| 功能           | MVP 包含                                          | 说明               |
| -------------- | ------------------------------------------------- | ------------------ |
| 一键 Docker 化 | ✅ 从原型代码生成 Dockerfile，多阶段构建，镜像扫描 | 镜像安全通过       |
| Compose 部署   | ✅ 生成单机 Compose 配置                           | 一键拉起           |
| 降级预案       | ✅ 预置模型宕机、超时、限流降级路径                | 演练通过           |
| 回滚           | ✅ 镜像版本回滚 ≤5 分钟                            | 已验证             |
| 裸机部署       | ✅ 生成 systemd 服务文件                           | 无 Docker 场景可用 |
