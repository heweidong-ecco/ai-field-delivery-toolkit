## 六、操作指南（使用工具包完成该项目）

### 第 1 天：需求诊断

```bash
# 1. 使用需求诊断器
python examples/diagnosis_example.py

# 2. 填写 AI 适用性五维评分
# 生成性：4（需要生成回答）
# 推理复杂度：3（需要一定推理）
# 不确定性容忍度：4（可接受不确定，但需准确）
# 数据可得性：5（文档充足）
# 实时性要求：2（响应可稍慢）
# 总分：18 → 推荐使用 AI

# 3. 生成诊断报告
python -c "
from diagnosis.checklist import AIFeasibilityChecklist
from diagnosis.report import DiagnosisReportGenerator
c = AIFeasibilityChecklist()
r = c.quick_evaluate(4,3,4,5,2)
g = DiagnosisReportGenerator()
report = g.generate('研发团队', '基于内部文档的智能问答', r, decision_maker='研发负责人')
g.save_report(report, 'pilot/diagnosis_report.json')
print('诊断报告已生成')
"
```

### 第 1 天：五步裁剪

```bash
# 使用裁剪引擎生成方案
python -c "
from cropper.constraints import *
from cropper.engine import crop_for_customer

constraints = CustomerConstraints(
    customer_id='rd-team',
    budget=100000,
    hardware=HardwareConstraints(cpu='8核', memory_gb=32, gpu=None),
    environment=EnvironmentConstraints(docker=True, network='internet', external_access=True),
    data=DataConstraints(total_records=400, daily_new=5, formats=['md','pdf'], quality='medium'),
    users=UserConstraints(total_users=30, concurrent_peak=10),
    compliance=ComplianceConstraints(data_residency='on-premise', pii_sensitive=True),
    timeline_weeks=2,
)
plan = crop_for_customer(constraints)
plan.save('pilot/crop_plan.json')
print('裁剪方案已生成')
print(f'启用模块: {plan.enabled_modules}')
print(f'删除模块: {plan.deleted_modules}')
"
```
