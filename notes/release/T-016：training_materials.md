# 培训材料大纲

## 培训目标
让 FDE 团队成员在半天内掌握工具包的使用方法。

## 课程安排

| 章节                | 内容                                    | 时长    |
| ------------------- | --------------------------------------- | ------- |
| 1. 环境准备         | Docker、Python、.env 配置、启动基础设施 | 15 分钟 |
| 2. 核心概念         | 模块介绍、目录结构、统一底座作用        | 30 分钟 |
| 3. 数据准备器实操   | 接入 CSV → 质量评估 → 清洗 → 评测集     | 60 分钟 |
| 4. 原型组装器实操   | 选择模板 → 创建 Agent → 运行            | 45 分钟 |
| 5. 五步裁剪引擎实操 | 输入客户约束 → 生成裁剪方案             | 30 分钟 |
| 6. 部署加固器实操   | 生成 Dockerfile → 生成 Compose/裸机配置 | 45 分钟 |
| 7. 监控与飞轮       | 查看监控指标、记录反馈、导出资产        | 30 分钟 |

## 实操练习
- 练习 1：用测试 CSV 跑通数据准备全流程
- 练习 2：创建一个知识问答 Agent 并运行
- 练习 3：为一个虚构客户生成裁剪方案
- 练习 4：生成部署配置并查看降级预案

## 考核标准
- 能独立跑通数据准备器
- 能创建并运行一个 Agent 原型
- 能使用裁剪引擎为任意客户生成方案
