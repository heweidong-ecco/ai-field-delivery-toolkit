**选择标准**：
- 内部项目，风险可控
- 有真实的历史数据（数据准备器有活干）
- 数据量适中（5万-50万条）
- 负责人愿意配合

**推荐候选**（按优先级）：

| 候选             | 场景                           | 数据类型          | 数据量      | 为什么选它                         |
| ---------------- | ------------------------------ | ----------------- | ----------- | ---------------------------------- |
| 研发知识库问答   | 内部文档问答                   | Markdown/PDF 文档 | 数百份文档  | 数据现成，风险低，FDE 团队自己也用 |
| 历史项目数据清洗 | 把已有项目的脏数据清洗成评测集 | 历史项目 JSON/CSV | 10万-50万条 | 直接复用，验证数据准备器           |
| 客服工单分析     | 内部客服工单分类               | 工单文本          | 5万-20万条  | 数据真实，场景明确                 |

**建议**：选择**研发知识库问答**作为首个试运行项目。理由：数据类型最简单（文档），场景边界清晰，团队成员自己就是用户，反馈直接。

**选定：研发知识库问答**

| 决策项       | 内容                                                 |
| ------------ | ---------------------------------------------------- |
| 客户名称     | 内部研发团队                                         |
| 场景         | 基于研发文档的智能问答                               |
| 数据来源     | `~/Desktop/ai-learning/` 下的全部 Markdown、PDF 文档 |
| 数据量       | 预计 200-500 份文档                                  |
| 数据质量     | 结构较好，但存在重复、格式混乱、未脱敏的密钥片段     |
| 配合程度     | 高，团队成员直接受益                                 |
| 风险         | 低，内部使用                                         |
| 验收人       | 研发团队负责人                                       |
| 开始时间     | 步骤 6 完成后启动                                    |
| 预计交付周期 | 10-14 天                                             |

**确认方式**：总工程师与研发负责人邮件确认，双方签字。
