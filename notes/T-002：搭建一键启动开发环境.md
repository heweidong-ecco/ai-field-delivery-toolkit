### 执行动作

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    container_name: toolkit-postgres
    environment:
      POSTGRES_USER: toolkit
      POSTGRES_PASSWORD: toolkit_dev
      POSTGRES_DB: toolkit
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U toolkit"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: toolkit-redis
    ports:
      - "6379:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 5s
      retries: 5

  chromadb:
    image: chromadb/chroma:latest
    container_name: toolkit-chroma
    ports:
      - "8000:8000"
    volumes:
      - chroma_data:/chroma/chroma

volumes:
  postgres_data:
  chroma_data:
```

创建 `requirements.txt`：

```
fastapi==0.115.0
uvicorn[standard]==0.30.0
pydantic==2.8.0
python-dotenv==1.0.1
sqlalchemy==2.0.31
asyncpg==0.29.0
redis==5.0.4
chromadb==0.5.0
openai==1.35.0
httpx==0.27.0
```

创建 `.env.example`：

```
# 数据库
POSTGRES_USER=toolkit
POSTGRES_PASSWORD=toolkit_dev
POSTGRES_DB=toolkit

# Redis
REDIS_URL=redis://localhost:6379/0

# ChromaDB
CHROMA_HOST=localhost
CHROMA_PORT=8000

# 模型 API（示例）
DEEPSEEK_API_KEY=sk-xxx
```

创建 `Makefile`（或 shell 脚本）：

```makefile
.PHONY: up down logs test

up:
	docker compose up -d

down:
	docker compose down

logs:
	docker compose logs -f

test:
	pytest tests/ -v

install:
	pip install -r requirements.txt
```

### 产出物

- `docker-compose.yml` 可一键启动 PostgreSQL、Redis、ChromaDB
- `requirements.txt` 完整
- `.env.example` 提供配置模板
- `Makefile` 提供常用命令

### 验收标准

- 执行 `docker compose up -d` 后三个服务健康
- 执行 `make install` 后依赖安装成功
- 新成员按 README 操作，30 分钟内跑通环境
